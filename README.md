# 🧩 How I Think About Engineering

```python
def build_system(problem):

    understand(problem)

    context = collect_context()
    data = validate(data_sources)
    
    prediction = learn(data)
    decision = optimize(prediction)

    decision = enforce_constraints(decision)
    decision = explain(decision)

    deploy(decision)
    observe(decision)

    return continuously_improve()
```

> **Build → Measure → Explain → Deploy → Observe → Improve**
